Xử lý bit

Phan Văn Việt — Trường THPT Chuyên Vĩnh Phúc

Mọi số trong máy tính đều là các bit 0/1. Hiểu biểu diễn bit và các phép toán trên bit cho ta những mẹo gọn, nhanh — và là nền tảng cho quy hoạch động trên tập con.

1.Biểu diễn bit

Số nguyên n bit lưu dưới dạng nhị phân. Ví dụ int 32 bit; số 43 là …0101011 vì 25 + 23 + 21 + 20 = 43. Bit đánh số từ phải sang trái.

int có dấu chứa −231 … 231−1; số âm dùng bù hai (đảo mọi bit rồi cộng 1), và ~x = −x − 1. Vượt giới hạn thì tràn — sau 231−1 là −231:

int x = 2147483647;   // 2^31 - 1
x++;                  // -2147483648

2.Các phép toán trên bit

Bốn phép cơ bản làm việc trên từng cột bit: AND & (cả hai là 1), OR | (ít nhất một là 1), XOR ^ (khác nhau), NOT ~ (đảo). Ví dụ 22 & 26 = 18, 22 | 26 = 30, 22 ^ 26 = 12. Bấm một phép để xem từng cột bit được tính:

Dịch bit: x << k nhân với 2k (thêm k số 0), x >> k chia cho 2k. Ví dụ 14 << 2 = 56, 49 >> 3 = 6. Từ đó có nhiều mẹo dùng mặt nạ 1 << k (chỉ bật bit thứ k):

Công thứcÝ nghĩa
x & 10 nếu x chẵn, 1 nếu x lẻ
x & (1 << k)lấy bit thứ k (khác 0 ⇔ bit k bật)
x | (1 << k)bật bit thứ k
x & ~(1 << k)tắt bit thứ k
x ^ (1 << k)lật bit thứ k
x & (x - 1)xoá bit 1 thấp nhất
x & -xgiữ đúng bit 1 thấp nhất
x & (x - 1) == 0x là luỹ thừa của 2 (x > 0)

Hàm đếm bit của g++: __builtin_popcount(x) đếm số bit 1, __builtin_ctz/clz đếm số bit 0 ở cuối/đầu. Ví dụ với x = 5328: popcount = 5, ctz = 4, clz = 19 (bản long long thêm hậu tố ll).

3.Biểu diễn tập hợp bằng mặt nạ bit

Mỗi tập con của {0, 1, …, n−1} là một số n bit: bit thứ i bật nghĩa là phần tử i có mặt. Ví dụ {1, 3, 4, 8} ứng với 28 + 24 + 23 + 21 = 282. Các phép trên tập trở thành phép bit:

for (int i = 0; i < n; i++)
    if (x & (1 << i)) cout << i << " ";   // in các phần tử của tập x

4.Tối ưu bằng bit

Khoảng cách Hamming giữa hai chuỗi bit (số vị trí khác nhau) tính bằng một dòng: XOR cho ra 1 ở đúng các vị trí khác nhau, rồi đếm:

int hamming(int a, int b) { return __builtin_popcount(a ^ b); }

Với 10 000 chuỗi dài 30 bit, cách ngây thơ mất 13,5 s, còn cách dùng bit chỉ 0,5 s — nhanh gần 30 lần. Cùng ý tưởng "xử lý nhiều bit một lúc" giúp bài đếm lưới con giảm từ O(n3) xuống O(n3/N) với N = 32 hoặc 64.

5.Quy hoạch động trên tập con

Vì trạng thái là một tập con nên lưu được thành một số nguyên, ta thường biến việc duyệt n! hoán vị thành duyệt 2n tập con (nhỏ hơn nhiều: n = 20 thì n! ≈ 2,4·1018 còn 2n ≈ 106).

Ví dụ: xếp thang máy
Thang tải tối đa x, n người có cân nặng cho trước. Cần ít nhất bao nhiêu lượt? Với mỗi tập con S, lưu cặp (số lượt, cân nặng lượt cuối); thêm dần từng người vào lượt cuối nếu còn chỗ, không thì mở lượt mới. Độ phức tạp O(2n · n) — thay cho O(n! · n) khi thử mọi thứ tự. 
for (int s = 1; s < (1 << n); s++) {
    best[s] = {n + 1, 0};
    for (int p = 0; p < n; p++) if (s & (1 << p)) {
        auto o = best[s ^ (1 << p)];              // bỏ người p khỏi tập
        if (o.second + weight[p] <= x) o.second += weight[p];  // ghép vào lượt cuối
        else { o.first++; o.second = weight[p]; }              // mở lượt mới
        best[s] = min(best[s], o);
    }
}
