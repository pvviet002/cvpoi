Vòng lặp while trong C++

Phan Văn Việt — Trường THPT Chuyên Vĩnh Phúc

Vòng for thường trả lời câu hỏi “lặp bao nhiêu lần?”. Vòng while trả lời một câu khác: “còn đúng điều kiện này thì tiếp tục”. Đó là công cụ tự nhiên cho những quá trình chưa biết trước số bước: đọc tới khi gặp số 0, tách chữ số cho tới khi số hết, chạy Euclid tới khi số dư bằng 0, hoặc thu hẹp một đoạn cho tới khi hai đầu gặp nhau.

Ý chính

Một vòng while là một quá trình biến đổi trạng thái. Trước mỗi lượt, máy hỏi điều kiện còn đúng không. Nếu đúng, thân vòng phải làm hai việc: tiến công việc và đưa trạng thái gần điều kiện dừng hơn. Nếu trạng thái không thay đổi đúng hướng, vòng lặp sẽ không bao giờ kết thúc.

1.Khi chưa biết trước số lượt lặp

Xét bài toán: bắt đầu từ số nguyên dương n, liên tục chia n cho 2 bằng phép chia nguyên cho tới khi nó bằng 0. Với n = 100, ta cần 7 lượt; với n = 109, ta cần 30 lượt. Số lượt không xuất hiện trực tiếp trong dữ liệu, nên viết bằng while tự nhiên hơn:

while (n > 0) {
    cout << n << " ";
    n /= 2;
}
for — biết trước miền duyệt
for (int i = 1; i <= n; i++)
    cout << i << " ";

Biến i đi qua một dãy đều đặn, số lượt xác định từ đầu.

while — biết điều kiện dừng
while (n > 0) {
    cout << n << " ";
    n /= 2;
}

Ta không đếm lượt; ta chỉ biết quá trình kết thúc khi n == 0.

Hai cấu trúc có sức mạnh như nhau

Mọi vòng for đều có thể viết lại bằng while, và ngược lại. Khác biệt nằm ở cách diễn đạt ý tưởng. Nếu đề cho một đoạn chỉ số rõ ràng, for thường gọn hơn. Nếu đề cho một điều kiện kết thúc hoặc một trạng thái thay đổi không đều, while thường dễ đọc hơn.

Thử tay: máy kiểm tra trước rồi mới chạy

Đặt giá trị ban đầu của i và cận n, rồi bấm từng bước. Chú ý trường hợp i > n ngay từ đầu: thân vòng không chạy lần nào.

2.Điều kiện duy trì và biến trạng thái

Cú pháp tổng quát:

khởi_tạo_trạng_thái;
while (điều_kiện_còn_đúng) {
    công_việc;
    cập_nhật_trạng_thái;
}

Máy thực hiện đúng ba bước lặp đi lặp lại:

Ba câu hỏi bắt buộc
  • Trạng thái là gì? Có thể là i, số đang xử lý n, hai số a, b, hoặc hai con trỏ l, r.
  • Điều kiện nào cho phép tiếp tục? Viết điều kiện theo nghĩa “còn việc thì làm”, không phải theo nghĩa “đã xong”.
  • Mỗi lượt tiến gần điểm dừng thế nào? Phải chỉ ra một đại lượng tăng có giới hạn, giảm có giới hạn, hoặc một đoạn bị thu hẹp.

Vòng lặp hữu hạn nhờ một đại lượng tiến triển

Đoạn while (i <= n) hoàn toàn đúng. Lỗi thường nằm trong thân: quên i++, cập nhật nhầm biến, hoặc có một nhánh continue đi qua trước khi cập nhật. Khi gỡ lỗi, hãy nhìn biến trạng thái sau từng lượt, không chỉ nhìn điều kiện.

3.Vòng lặp lính canh và đọc đến EOF

Lính canh: một giá trị báo “hết dữ liệu”

Đề có thể cho một dãy số không biết dài bao nhiêu, kết thúc bởi số 0. Số 0 không thuộc dữ liệu thật; nó là lính canh:

long long x, sum = 0;
cin >> x;
while (x != 0) {
    sum += x;
    cin >> x;
}
cout << sum;

Ở đây có hai lần nhập cùng một biến: một lần trước vòng để có điều kiện đầu tiên, một lần cuối thân để chuẩn bị cho lượt kế tiếp. Khuôn này gọi là đọc mồi — xử lý — đọc lại.

Cách viết gọn khi toán tử nhập nằm trong điều kiện
long long x, sum = 0;
while (cin >> x && x != 0)
    sum += x;

Biểu thức cin >> x có thể được dùng như một điều kiện: đúng nếu đọc thành công, sai nếu hết tệp hoặc dữ liệu lỗi. Nhờ chập mạch, nếu đọc thất bại thì x != 0 không được tính.

Đọc tới cuối tệp — EOF

Một số đề không cho n và cũng không có lính canh; dữ liệu kết thúc khi tệp hết. Khi ấy viết:

long long x;
while (cin >> x) {
    // xử lý x
}
Không viết while (!cin.eof())

Cờ EOF chỉ bật sau khi một lần đọc thất bại. Vì vậy khuôn while (!cin.eof()) thường khiến thân vòng chạy thêm một lượt với giá trị cũ. Hãy đặt chính phép đọc vào điều kiện: while (cin >> x).

4.Bốn khuôn mẫu quan trọng

Khuôn A — lặp bằng biến đếm

Dùng được khi số lượt đã biết, dù trong trường hợp đó for thường gọn hơn. Viết khuôn này giúp thấy rõ ba phần của vòng while nằm ở ba vị trí khác nhau:

int i = 1;                  // khởi tạo
while (i <= n) {            // kiểm tra
    cout << i << " ";     // công việc
    i++;                    // cập nhật
}

Khuôn B — tách chữ số của một số nguyên

Với số dương n, chữ số cuối là n % 10; bỏ chữ số cuối bằng n /= 10. Hai phép này tạo nên cả một họ bài:

long long n;
cin >> n;
long long sum = 0;
while (n > 0) {
    int digit = n % 10;
    sum += digit;
    n /= 10;
}
cout << sum;

Chữ số lớn nhấtmx = max(mx, digit)

Kiểm tra đối xứngđảo số rồi so với bản gốc
Trường hợp n = 0

Vòng while (n > 0) không chạy với n = 0, nhưng số 0 có một chữ số. Nếu bài đếm chữ số và cho phép 0, phải xử lý riêng hoặc dùng do-while.

Thử tay: bóc từng chữ số

Mỗi lần bấm, máy lấy chữ số cuối rồi xóa nó khỏi số. Chữ số xuất hiện theo thứ tự từ phải sang trái, đúng với cách phép chia dư hoạt động.

Khuôn C — thuật toán Euclid tìm UCLN

Đẳng thức nền tảng là gcd(a,b) = gcd(b,a mod b). Ta liên tục thay cặp số bằng cặp nhỏ hơn cho tới khi số thứ hai bằng 0:

long long a, b;
cin >> a >> b;
while (b != 0) {
    long long r = a % b;
    a = b;
    b = r;
}
cout << a;

Đây là ví dụ điển hình của while: số lượt không biết trước, nhưng mỗi lượt số dư r thỏa 0 ≤ r < b, nên trạng thái tiến chắc chắn về b = 0.

Khuôn D — hai con trỏ thu hẹp một đoạn

Kiểm tra chuỗi đối xứng là một quá trình chưa biết chính xác bao nhiêu lượt nếu ta chỉ nghĩ theo điều kiện “hai đầu chưa gặp nhau”:

int l = 0, r = (int)s.size() - 1;
bool ok = true;
while (l < r) {
    if (s[l] != s[r]) {
        ok = false;
        break;
    }
    l++;
    r--;
}
cout << (ok ? "YES" : "NO");

Đại lượng tiến triển là độ dài đoạn đang xét: sau mỗi lượt nó giảm 2. Vòng dừng khi l >= r hoặc khi phát hiện một cặp khác nhau.

Một khuôn chương trình hoàn chỉnh
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n;
    cin >> n;

    long long original = n;
    long long reversed = 0;

    do {
        int digit = n % 10;
        reversed = reversed * 10 + digit;
        n /= 10;
    } while (n > 0);

    cout << (original == reversed ? "YES" : "NO") << '\n';
    return 0;
}

do-while được dùng để số 0 cũng đi qua thân vòng đúng một lần.

5.do-while, break và continue

do-while: chạy trước, kiểm tra sau

while — có thể chạy 0 lần
while (condition) {
    work();
}
do-while — chạy ít nhất 1 lần
do {
    work();
} while (condition);

Dấu chấm phẩy sau while (condition); của do-while là bắt buộc. Cấu trúc này phù hợp với menu cần hiển thị ít nhất một lần, hoặc xử lý chữ số của 0.

break: thoát ngay khỏi vòng gần nhất

int i = 2;
while (i * i <= n) {
    if (n % i == 0) {
        cout << "KHONG NGUYEN TO";
        break;
    }
    i++;
}

break chỉ thoát vòng gần nhất. Với vòng lặp lồng nhau, nó không tự thoát tất cả các tầng.

continue: bỏ phần còn lại của lượt hiện tại

Trong while, continue đặc biệt nguy hiểm vì phần cập nhật thường nằm cuối thân vòng:

Sai — gặp số chẵn là mắc kẹt
int i = 1;
while (i <= n) {
    if (i % 2 == 0) continue;
    cout << i << " ";
    i++;
}
Đúng — cập nhật trước khi continue
int i = 1;
while (i <= n) {
    if (i % 2 == 0) {
        i++;
        continue;
    }
    cout << i << " ";
    i++;
}
Cách tốt hơn: tránh continue nếu điều kiện viết lại được
int i = 1;
while (i <= n) {
    if (i % 2 != 0) cout << i << " ";
    i++;
}

Mọi đường đi qua thân vòng đều chạm cùng một lệnh cập nhật. Cấu trúc này ít rủi ro hơn.

6.Độ phức tạp và những cái bẫy

Không nhìn chữ while để đo độ phức tạp

Phải hỏi trạng thái thay đổi nhanh đến đâu:

Cập nhậtSố lượt điển hìnhĐộ phức tạp
i++ từ 1 tới nnO(n)
n /= 10số chữ số của nO(log n)
n /= 2số bit của nO(log n)
Euclidtối đa theo log của số nhỏ hơnO(log min(a,b))
mỗi lượt tăng l hoặc giảm rtối đa n lần tổng cộngO(n)

Bảy cái bẫy

1. Quên cập nhật
int i = 1;
while (i <= n)
    cout << i;   // i mãi bằng 1

Nếu n >= 1, điều kiện không bao giờ đổi.

2. Cập nhật sai hướng
while (i <= n) {
    ...
    i--;          // càng lúc càng xa n + 1
}

Điều kiện cần i tăng để trở thành sai, nhưng chương trình lại giảm nó.

3. Dấu chấm phẩy tạo thân rỗng
while (i <= n); {
    cout << i;
    i++;
}

Thân thật của vòng là câu lệnh rỗng sau dấu chấm phẩy. Khối ngoặc phía sau không thuộc vòng và không bao giờ được tới nếu vòng rỗng bị mắc kẹt.

4. Nhập mồi nhưng quên nhập lại
cin >> x;
while (x != 0) {
    sum += x;
    // thiếu cin >> x;
}

x giữ nguyên, nên nếu ban đầu khác 0 thì vòng chạy mãi.

5. Xử lý lính canh như dữ liệu thật
while (true) {
    cin >> x;
    sum += x;          // đã cộng trước khi kiểm tra
    if (x == -1) break;
}

Nếu -1 chỉ là dấu kết thúc, tổng đã bị cộng sai. Kiểm tra lính canh trước khi xử lý.

6. Mất giá trị gốc khi tách chữ số

Sau vòng while (n > 0) n /= 10;, biến n đã bằng 0. Nếu còn cần số ban đầu để so sánh, hãy lưu long long original = n; trước vòng.

7. Tràn số trong điều kiện
while (i * i <= n) ...

Nếu i là int, phép nhân có thể tràn trước khi so với n. Dùng 1LL * i * i <= n hoặc viết i <= n / i khi phù hợp.

Bốn câu tự hỏi trước khi nộp
  • Điều kiện được viết theo nghĩa còn tiếp tục hay đã vô tình viết theo nghĩa đã xong?
  • Mọi đường đi trong thân vòng có làm trạng thái thay đổi không, kể cả nhánh có continue?
  • Có một đại lượng tăng, giảm hoặc thu hẹp để chứng minh vòng chắc chắn dừng không?
  • Trường hợp trạng thái ban đầu đã ở điểm dừng — như n = 0 — có cần thân vòng chạy một lần không?

7.Lộ trình luyện tập

Làm theo bốn chặng dưới đây. Mỗi chặng thêm đúng một kiểu trạng thái mới.

Mười hai bài tự luyện theo thứ tự
  1. In các số từ 1 đến n bằng while.
  2. In các số từ n về 1.
  3. Tính tổng các số chẵn không vượt quá n.
  4. Đếm số chữ số của n, kể cả n = 0.
  5. Tính tổng và tích các chữ số.
  6. Đảo một số nguyên không âm.
  7. Kiểm tra số đối xứng.
  8. Đọc các số tới khi gặp 0, in số lớn nhất đã đọc.
  9. Đọc tới EOF và đếm có bao nhiêu số âm.
  10. Tìm UCLN và BCNN của hai số.
  11. Phân tích n thành thừa số nguyên tố.
  12. Kiểm tra chuỗi đối xứng bằng hai con trỏ.
Kết luận cần nhớ

Đừng bắt đầu bằng việc hỏi “dùng while hay for?”. Hãy hỏi: trạng thái hiện tại là gì, khi nào còn phải làm, và mỗi lượt làm trạng thái tiến về đâu? Khi ba câu này rõ ràng, vòng lặp chỉ còn là cách ghi lại quá trình ấy bằng cú pháp C++.
