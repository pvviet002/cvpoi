Vòng lặp for trong C++

Phan Văn Việt — Trường THPT Chuyên Vĩnh Phúc

Viết một vòng for để in các số từ 1 đến n không khó. Phần dễ sai bắt đầu khi đề yêu cầu đi lùi, nhảy bước, duyệt một đoạn đóng, duyệt mảng từ chỉ số 0, bỏ qua một vài phần tử hoặc lồng hai vòng với nhau. Chương trình vẫn dịch, vẫn chạy, nhưng có thể thừa đúng một lượt, thiếu đúng một lượt hoặc không dừng.

Ý chính

Một vòng for là một chuỗi trạng thái hữu hạn. Mỗi lượt đều đi qua cùng bốn bước: khởi tạo → kiểm tra → thực hiện thân vòng → cập nhật. Muốn viết đúng, phải trả lời được ba câu: biến lặp bắt đầu ở đâu, được phép đi tới đâu, và sau mỗi lượt nó thay đổi thế nào.

1.Một vòng lặp thực sự chạy thế nào

Xét đoạn chương trình quen thuộc:

for (int i = 1; i <= 4; i++)
    cout << i << " ";

Nhìn trên một dòng, ba phần trong ngoặc dễ tạo cảm giác chúng được thực hiện cùng lúc. Thật ra thứ tự của máy là:

Điều thường bị hiểu nhầm

Phần khởi tạo chỉ chạy một lần duy nhất. Điều kiện được kiểm tra trước mỗi lượt, kể cả trước lượt đầu tiên. Phần cập nhật chạy sau thân vòng. Vì thế, nếu điều kiện sai ngay từ đầu thì thân vòng không chạy lần nào.

Thử tay: cho máy chạy từng bước

Chọn n, rồi bấm Bước tiếp. Dòng màu xanh là bước máy đang thực hiện; vùng kết quả chỉ thay đổi khi thân vòng được chạy.

2.Ba phần trong câu lệnh for

Cú pháp tổng quát:

for (khởi_tạo; điều_kiện; cập_nhật) {
    công_việc_lặp_lại;
}
PhầnVai tròVí dụSố lần chạy
Khởi tạoTạo trạng thái ban đầuint i = 11
Điều kiệnQuyết định có vào lượt tiếp theo khôngi <= nsố lượt + 1
Thân vòngCông việc cần lặpsum += isố lượt
Cập nhậtĐưa trạng thái tới lượt kế tiếpi++số lượt

Với vòng từ 1 tới n, biến i không chỉ là “số đếm”. Nó thường mang một ý nghĩa cụ thể: chỉ số phần tử đang xét, giá trị ứng viên đang thử, số dòng đang in, hoặc số bước đã thực hiện. Đặt tên và hiểu đúng ý nghĩa ấy giúp viết điều kiện chính xác hơn.

Bất biến đơn giản nhất

Ngay trước mỗi lượt của for (int i = 1; i <= n; i++), ta biết rằng mọi giá trị từ 1 đến i - 1 đã được xử lý, còn i là giá trị tiếp theo. Mệnh đề luôn đúng ấy gọi là bất biến vòng lặp.

Ba cách cập nhật thường gặp

Tăng đều
for (int i = 1; i <= n; i++)
    cout << i;
Giảm đều
for (int i = n; i >= 1; i--)
    cout << i;
Nhảy bước cố định
for (int i = 0; i <= n; i += 2)
    cout << i;
Tăng theo cấp số nhân
for (long long i = 1; i <= n; i *= 2)
    cout << i;
Câu hỏi kiểm tra phần cập nhật

Sau mỗi lượt, biến lặp có tiến gần tới lúc điều kiện sai không? Nếu không, vòng lặp có thể chạy vô hạn. Ví dụ i <= n mà lại cập nhật i-- thì i càng lúc càng xa biên thoát.

3.Biên lặp và số lần thực hiện

Phần lớn lỗi vòng lặp là lỗi biên. Hai đoạn dưới chỉ khác một dấu bằng nhưng số lượt khác nhau:

Đoạn nửa mở [L, R)
for (int i = L; i < R; i++)
    ...;
// L, L+1, ..., R-1
Đoạn đóng [L, R]
for (int i = L; i <= R; i++)
    ...;
// L, L+1, ..., R
Dạng lặpCác giá trị của iSố lượt
i = L; i < R; i++L, L+1, …, R−1max(0, R−L)
i = L; i <= R; i++L, L+1, …, Rmax(0, R−L+1)
i = R; i >= L; i--R, R−1, …, Lmax(0, R−L+1)
i = L; i <= R; i += kcách nhau k⌊(R−L)/k⌋+1, nếu L≤R
Mảng dùng đoạn nửa mở

Mảng có n phần tử mang chỉ số từ 0 đến n−1. Vì vậy khuôn an toàn là for (int i = 0; i < n; i++). Viết i <= n sẽ chạm vào a[n], một phần tử không tồn tại.

Thử tay: một dấu bằng thay đổi điều gì?

Nhập hai đầu L, R, rồi bật hoặc tắt lựa chọn “lấy cả R”. Mô phỏng sẽ liệt kê chính xác các giá trị biến lặp nhận được.

4.Bốn khuôn mẫu quan trọng

Khuôn A — lặp đúng n lần

Khi đề nói “thực hiện n lần” mà không cần giá trị từ 1 tới n, dùng chỉ số 0 là tự nhiên nhất:

for (int i = 0; i < n; i++) {
    // chạy đúng n lần
}

Nếu cần in số thứ tự cho người đọc, dùng i + 1. Không cần đổi cả cấu trúc vòng sang 1-based chỉ để hiển thị.

Khuôn B — cộng dồn và đếm

Hai biến tích luỹ phổ biến nhất là tổng và số lượng. Chúng phải được khởi tạo trước vòng lặp:

long long sum = 0;
int cnt = 0;
for (int i = 0; i < n; i++) {
    cin >> a[i];
    sum += a[i];
    if (a[i] % 2 == 0) cnt++;
}
Đặt biến tích luỹ sai chỗ

Nếu viết long long sum = 0; bên trong thân vòng, tổng bị đặt lại về 0 ở mỗi lượt. Kết quả cuối cùng chỉ còn phần tử cuối, không phải tổng cả dãy.

Khuôn C — tìm giá trị tốt nhất

Muốn tìm lớn nhất trong dữ liệu, lấy phần tử đầu làm đáp án ban đầu rồi duyệt phần còn lại:

long long best;
cin >> best;
for (int i = 1; i < n; i++) {
    long long x; cin >> x;
    if (x > best) best = x;
}
cout << best;

Cách này đúng cả khi mọi số đều âm. Khởi tạo best = 0 sẽ sai với dãy -8 -3 -10.

Khuôn D — sinh cấu trúc theo hàng và cột

Vòng ngoài chọn hàng, vòng trong xử lý từng cột của hàng ấy:

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++)
        cout << i * j << " ";
    cout << "\n";
}
Khuôn chung của bài duyệt dãy
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    cin >> n;

    long long sum = 0;
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;              // 1. lấy phần tử thứ i
        sum += x;               // 2. cập nhật thông tin chung
        if (x > 0) cnt++;       // 3. kiểm tra tính chất nếu cần
    }

    cout << sum << " " << cnt << "\n";
    return 0;
}

Trước mỗi lượt, sum là tổng và cnt là số phần tử dương của đúng các phần tử đã đọc. Đó là bất biến giúp chứng minh chương trình đúng.

5.break, continue và vòng lặp lồng nhau

break — dừng ngay vòng gần nhất

Dùng khi đã có đủ thông tin và mọi lượt còn lại không thể thay đổi đáp án:

bool found = false;
for (int i = 0; i < n; i++) {
    if (a[i] == x) {
        found = true;
        break;
    }
}

continue — bỏ phần còn lại của lượt hiện tại

long long sumPositive = 0;
for (int i = 0; i < n; i++) {
    if (a[i] <= 0) continue;
    sumPositive += a[i];
}
break

Thoát khỏi toàn bộ vòng lặp đang chứa nó. Luồng chạy tiếp ở câu lệnh sau vòng.

continue

Chỉ kết thúc lượt hiện tại. Với for, máy vẫn chạy phần cập nhật rồi kiểm tra lượt mới.

break chỉ thoát một tầng

Trong hai vòng lồng nhau, break nằm ở vòng trong chỉ thoát vòng trong. Vòng ngoài vẫn tiếp tục. Muốn dừng cả hai tầng, dùng biến cờ, tách thành hàm rồi return, hoặc thiết kế lại điều kiện.

Thử tay: thứ tự duyệt của hai vòng lồng nhau

Mỗi ô mang tọa độ (i, j). Quan sát để thấy j chạy hết một hàng trước khi i tăng.

6.Độ phức tạp và những cái bẫy

Đếm lượt trước khi tối ưu

Mẫu vòng lặpSố lượt xấp xỉĐộ phức tạp
for (i = 0; i < n; i++)nO(n)
for (i = 1; i <= n; i *= 2)log₂n + 1O(log n)
Hai vòng độc lập, mỗi vòng chạy n lượt2nO(n)
Hai vòng lồng nhau, mỗi vòng chạy n lượtn²O(n²)
for (j = i; j < n; j++) bên trongn(n+1)/2O(n²)

Sáu cái bẫy

1. Dấu chấm phẩy sau for
for (int i = 0; i < n; i++);  // thân vòng rỗng
    sum += i;                  // không thuộc vòng lặp

Dấu ; đã trở thành thân vòng. Khối thụt vào phía dưới chỉ chạy một lần sau khi vòng kết thúc.

2. Sửa biến lặp trong thân vòng

Với for (...; i++), nếu thân vòng lại có i++, mỗi lượt biến tăng hai lần. Một nửa giá trị bị bỏ qua, còn việc đọc mã trở nên khó đoán.

3. unsigned đi lùi
for (unsigned i = n - 1; i >= 0; i--)  // không dừng như mong đợi
    ...;

Kiểu không dấu không có số âm. Sau 0, nó cuộn về một số rất lớn. Khi cần đi lùi, dùng kiểu có dấu hoặc viết khuôn phù hợp như for (int i = n - 1; i >= 0; i--).

4. Tràn ở biến tích luỹ

Tổng của 105 số, mỗi số tới 109, có thể đạt 1014. Biến int không chứa được; tổng phải là long long.

5. Khai báo biến lặp ngoài ý muốn

Biến i khai báo trong for (int i = ...) chỉ tồn tại trong vòng và khối của nó. Dùng i sau vòng sẽ lỗi biên dịch. Đây thường là điều tốt vì ngăn biến đếm rò rỉ sang đoạn mã khác.

6. O(n²) khi n quá lớn

Hai vòng lồng nhau với n = 105 có thể tạo tới 1010 lượt — vượt xa thời gian thi. Trước khi viết vòng trong, hãy ước lượng số lượt lớn nhất.

Bốn câu tự hỏi trước khi bấm nộp
  • Giá trị đầu tiên và giá trị cuối cùng của biến lặp là gì?
  • Vòng chạy chính xác bao nhiêu lượt, kể cả trường hợp n = 0?
  • Phần cập nhật có luôn đưa biến lặp gần tới điều kiện dừng không?
  • Tổng số lượt của mọi vòng lồng nhau có phù hợp giới hạn dữ liệu không?

Cách tự kiểm một bài vòng lặp

Không chỉ chạy ví dụ lớn. Hãy thử ít nhất bốn trường hợp: kích thước 0 nếu đề cho phép, kích thước 1, một trường hợp vừa đủ để nhìn tay, và giới hạn lớn nhất để kiểm tra thời gian cùng kiểu dữ liệu. Lỗi biên thường lộ ở hai trường hợp đầu; lỗi độ phức tạp lộ ở trường hợp cuối.
