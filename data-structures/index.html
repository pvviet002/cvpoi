Cấu trúc dữ liệu (STL)

Phan Văn Việt — Trường THPT Chuyên Vĩnh Phúc

Chọn đúng cấu trúc dữ liệu là mấu chốt của nhiều bài toán. Thư viện chuẩn C++ (STL) cho sẵn những cấu trúc mạnh; biết ưu — nhược của từng loại giúp ta viết mã nhanh và chạy nhanh.

1.Mảng động: vector

vector là mảng có thể phình to lúc chạy, dùng gần như mảng thường:

vector<int> v;
v.push_back(3);           // [3]
v.push_back(2);           // [3,2]
cout << v[0] << " " << v.size() << "\n";   // 3 2
for (auto x : v) cout << x << "\n";        // duyệt gọn
v.pop_back();             // bỏ phần tử cuối
vector<int> a(10, 5);     // 10 phần tử, mỗi phần tử = 5

Bên trong, khi mảng đầy, vector cấp mảng mới lớn hơn và chép sang — nhưng việc đó hiếm, nên push_back tốn trung bình O(1).

2.Tập hợp (set) và bảng tra (map)

set giữ một tập phần tử, hỗ trợ chèn / đếm / xóa; mọi phần tử phân biệt (thêm trùng không tăng số lượng):

set<int> s;
s.insert(3); s.insert(2); s.insert(5);
cout << s.count(3) << "\n";   // 1  (có)
s.erase(3);
cout << s.count(3) << "\n";   // 0  (đã xóa)

map là “mảng” mà chỉ số (khoá) có thể thuộc kiểu bất kỳ, ánh xạ khoá → giá trị:

map<string,int> m;
m["banana"] = 3;
cout << m["banana"] << "\n";      // 3
if (m.count("apple")) { /* khoá tồn tại? */ }

Cần duyệt theo thứ tự hoặc dùng lower_bound thì chọn loại có thứ tự; chỉ cần chèn/tra nhanh thì bản băm nhanh hơn.

3.Trình lặp và phạm vi

Trình lặp là biến trỏ tới một phần tử. Hai trình lặp hay dùng là begin() (phần tử đầu) và end() (ngay sau phần tử cuối) — nên phạm vi là nửa mở [begin, end). Rất nhiều hàm nhận một phạm vi như vậy:

sort(v.begin(), v.end());        // hoặc sort(a, a+n) với mảng thường
auto it = s.lower_bound(x);      // phần tử nhỏ nhất >= x (chỉ set có thứ tự)

lower_bound(x) trả trình lặp tới phần tử nhỏ nhất ≥ x, upper_bound(x) tới phần tử nhỏ nhất > x; nhờ chúng ta tìm nhanh “phần tử gần x nhất” trong tập có thứ tự.

4.Vài cấu trúc thường gặp khác

  • stack — vào sau ra trước (LIFO): push, pop, top, đều O(1).
  • queue — vào trước ra trước (FIFO): push, pop, front, đều O(1).
  • priority_queue — luôn lấy ra phần tử lớn nhất (mặc định); chèn/xóa O(log n), xem đỉnh O(1).
  • deque — thêm/xóa hiệu quả ở cả hai đầu (push_front/push_back).
  • bitset — mảng bit, mỗi phần tử đúng 1 bit; tiết kiệm bộ nhớ và làm phép bit hàng loạt.

Điểm dễ nhầm nhất là stack và queue lấy phần tử ra theo thứ tự ngược nhau. Nhập một dãy, bấm Chạy: cả hai nhận cùng các phần tử, nhưng thứ tự lấy ra khác hẳn.

5.Cấu trúc dữ liệu hay sắp xếp?

Nhiều bài giải được bằng cấu trúc dữ liệu hoặc bằng sắp xếp; hiệu quả thực tế có thể chênh nhau nhiều dù cùng độ phức tạp. Ví dụ: đếm số phần tử có mặt ở cả hai danh sách A, B (mỗi danh sách n số).

Ba cách
  • Cách 1 — cho A vào set, duyệt B tra: O(n log n).
  • Cách 2 — đổi sang unordered_set: O(n) trung bình.
  • Cách 3 — sắp xếp cả hai rồi duyệt song song: O(n log n).

Đo thực tế: cách 2 nhanh hơn cách 1 khoảng 4–5 lần; và tuy cách 1 với cách 3 cùng O(n log n), cách 3 vẫn nhanh hơn tới cả chục lần — vì sắp xếp là thủ tục đơn giản chạy một lần, còn cây cân bằng phải duy trì suốt quá trình. Bài học: cùng O(·) chưa chắc cùng tốc độ; hệ số hằng rất đáng kể.
