Phần 2 · Kiểu char

Mỗi ký tự là một con số

'0' … '9'

mã 48 … 57

'A' … 'Z'

mã 65 … 90

'a' … 'z'

mã 97 … 122

+32: 'A' là 65, 'a' là 97

Thử ngay

1  char c = 'A';

2  cout << (int) c << ' ';

3  cout << (char) (c + 1);

Màn hình

65 B

Máy không lưu hình dáng chữ, chỉ lưu mã ASCII của nó, một số nguyên. Ba dải ký tự hay gặp có mã liên tiếp nhau.

(int) c cho thấy con số 65. c + 1 là 66; ép về char thì in ra chữ B.

Là số nên so sánh được: 'A' < 'a' vì 65 < 97.

Phần 2 · Kiểu char

Ba phép đổi dùng suốt năm học

1. Giá trị của chữ số

'7' - '0'

55 − 48 = 7

Đổi ký tự '0' … '9' thành số 0 … 9.

2. Hoa sang thường

'C' - 'A' + 'a'

67 − 65 + 97 = 99

Mã 99 là chữ 'c'. Viết gọn: tolower(c).

3. Chữ cái thứ mấy

'e' - 'a'

101 − 97 = 4

Đếm từ 0: 'a' là 0, 'e' là 4. Dùng làm chỉ số mảng đếm.

Kiểm tra c có phải chữ số

Vì mã liên tiếp: c >= '0' && c <= '9', hoặc dùng hàm có sẵn isdigit(c). Tương tự có isalpha, isupper, islower.
