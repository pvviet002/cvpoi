Bài toán: tổng từ 1 đến n

Cho số nguyên dương n. Tính tổng

S(n) = 1 + 2 + … + n

Ví dụ

n = 5: 1 + 2 + 3 + 4 + 5 = 15

Cách quen thuộc: vòng lặp

1  int s = 0;

2  for (int i = 1; i <= n; i++)

3      s += i;

4  cout << s;

Vòng lặp cộng dần từng số, ai cũng viết được. Hôm nay ta nhìn bài toán này theo một cách khác.

1  long long P(int a, int n) {

2      if (n == 0) return ___;

4  }

P(a, n) là a nhân với chính nó n lần. Ví dụ P(3, 4) = 3 × 3 × 3 × 3 = 81.

Điền hai chỗ trống để hàm tính đúng P(a, n).

Chỗ trống thứ nhất · điểm dừng

Khi n = 0, P(a, 0) bằng bao nhiêu?

Chỗ trống thứ hai · bước thu nhỏ

P(3, 4) = 3 × (3 × 3 × 3) = 3 × P(3, 3).

Vậy P(a, n) = ? × P(a, n − 1).

Phần 3 · Hai thứ không được thiếu

Lũy thừa: đáp án

Cây lời gọi của P(3, 4)

1  long long P(int a, int n) {

2      if (n == 0) return 1;

4  }

Điểm dừng: P(a, 0) = 1. Bước thu nhỏ: P(a, n) = a × P(a, n − 1). Tính P(3, 4) mất 5 lời gọi.
