Tìm kiếm hoàn chỉnh

Phan Văn Việt — Trường THPT Chuyên Vĩnh Phúc

Tìm kiếm hoàn chỉnh (vét cạn) sinh ra mọi giải pháp khả dĩ rồi chọn cái tốt nhất hoặc đếm số giải pháp. Nó dễ cài, luôn cho đáp án đúng — miễn là kịp thời gian. Khi vét cạn quá chậm, ta mới cần tới tham lam hay quy hoạch động.

1.Sinh tập con

Một tập n phần tử có 2n tập con. Có hai cách sinh. Cách đệ quy: với mỗi phần tử, quyết định lấy hay không:

void search(int k) {
    if (k == n) { /* xử lý tập con */ }
    else {
        search(k+1);                 // không lấy phần tử k
        subset.push_back(k);
        search(k+1);                 // lấy phần tử k
        subset.pop_back();
    }
}

Cách dùng bit: mỗi số b từ 0 đến 2n−1 là một tập con — bit thứ i bật nghĩa là lấy phần tử i. Ví dụ 25 = 110012 ứng với tập {0, 3, 4}:

for (int b = 0; b < (1 << n); b++) {      // 1<<n bằng 2^n
    for (int i = 0; i < n; i++)
        if (b & (1 << i)) subset.push_back(i);
}

2.Sinh hoán vị

Một tập n phần tử có n! hoán vị. Cách đệ quy dùng mảng chosen đánh dấu phần tử đã lấy; hoặc gọn hơn, dùng hàm chuẩn next_permutation để nhảy sang hoán vị kế tiếp:

vector<int> p;
for (int i = 0; i < n; i++) p.push_back(i);
do {
    // xử lý hoán vị p
} while (next_permutation(p.begin(), p.end()));

3.Quay lui: bài toán N quân hậu

Quay lui dựng giải pháp từng bước; khi một bước không thể mở rộng, ta lùi lại và thử cách khác. Kinh điển là đặt n quân hậu lên bàn n×n sao cho không quân nào ăn được quân nào: đặt lần lượt mỗi hàng một quân, chỉ chọn cột mà cột và hai đường chéo chưa bị chiếm.

void search(int y) {           // đặt quân ở hàng y
    if (y == n) { count++; return; }        // đủ n quân -> một nghiệm
    for (int x = 0; x < n; x++) {
        if (column[x] || diag1[x+y] || diag2[x-y+n-1]) continue;
        column[x] = diag1[x+y] = diag2[x-y+n-1] = 1;
        search(y+1);
        column[x] = diag1[x+y] = diag2[x-y+n-1] = 0;   // quay lui
    }
}

Gọi q(n) là số cách đặt. Thuật toán cho q(8) = 92; số nghiệm tăng theo hàm mũ nên q(16) = 14 772 512 đã mất cả phút. Bấm Chạy để xem quay lui dò tới nghiệm đầu tiên: ô đang thử viền xanh, xung đột gạch đỏ, đặt được thì hiện quân hậu, bí thì quay lui (viền đỏ nét đứt).

4.Cắt tỉa cây tìm kiếm

Cây quay lui thường rất lớn, nên nhận ra sớm một nhánh không thể dẫn tới nghiệm sẽ tiết kiệm rất nhiều. Xét bài đếm đường đi qua mỗi ô đúng một lần trong lưới 7×7 (có 111 712 đường). Thêm dần các nhận xét cắt tỉa:

Phiên bảnThời gianSố lần gọi đệ quy
Quay lui thuần483 s76 tỉ
+ đối xứng bước đầu244 s38 tỉ
+ dừng nếu tới đích quá sớm119 s20 tỉ
+ phát hiện lưới bị chia đôi1,8 s221 triệu
+ mở rộng nhận xét chia đôi0,6 s69 triệu

Từ 483 s xuống 0,6 s — nhanh gần 1000 lần chỉ nhờ vài nhận xét. Mấu chốt: cắt tỉa càng gần gốc cây (những bước đầu) thì càng loại được nhiều nhánh.

5.Chia đôi rồi ghép (gặp nhau ở giữa)

Kỹ thuật gặp nhau ở giữa chia không gian tìm kiếm thành hai nửa, tìm riêng mỗi nửa rồi ghép kết quả — thường biến 2n thành 2n/2 (vì 2n/2 = √(2n)).

Ví dụ: chọn vài số cho tổng bằng x
Danh sách [2, 4, 5, 9], x = 15. Chia A = [2, 4], B = [5, 9]. Mọi tổng con: SA = [0, 2, 4, 6], SB = [0, 5, 9, 14]. Có 6 ∈ SA và 9 ∈ SB, 6 + 9 = 15 → chọn được (ứng với [2, 4, 9]).

Sắp xếp hai danh sách tổng rồi quét bằng hai con trỏ, kiểm tra "có u ∈ SA, v ∈ SB với u + v = x?" trong O(2n/2).
